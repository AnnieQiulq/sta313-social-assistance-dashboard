Development Plan

We plan to build an interactive web-based dashboard using HTML, CSS, JavaScript, and D3.js. We will use Statistics Canada CMA boundary data in GeoJSON format for the choropleth map and process Ontario Works (OW), Ontario Disability Support Program (ODSP), and CMA population data using R or Python before exporting structured datasets for the website. Users will be able to select a year range and program, compare percentage changes in caseload rates across CMAs, and explore linked rankings, historical trends, and demographic breakdowns. To divide the work, Member 1 will coordinate data sourcing and cleaning; Member 2 will validate population denominators, rate calculations, and data documentation; Member 3 will develop the interactive map and geographic inset; Member 4 will implement the ranking and time-series visualizations; Member 5 will develop demographic views and linked filters; and Member 6 will integrate the interface, test interactions, and prepare deployment and documentation. All members will review the analytical interpretations and conduct final usability and accuracy checks. We plan to publish the dashboard as a static website using GitHub Pages, while retaining source code and data-processing documentation for reproducibility.
